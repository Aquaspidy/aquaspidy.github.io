What It Does

Voop's Play Recognition module analyzes player positioning in real time to identify offensive and defensive formations. Using spatial pattern recognition, the system detects formations like 2-3 Zone Defense, Horns, 1-3-1, Flex, and 3-2 Zone Defense.

But recognition alone isn't enough. For each detected formation, Voop provides an instant counter-plan — actionable advice on how to exploit the formation. For a 2-3 zone, the counter might be "attack the high post with a passer." For Horns offense, it might be "deny the high post entry and force the guard baseline."

This is like having an assistant coach watching the game with you, identifying patterns, and suggesting adjustments — all in real time.

How It Works

📍 Zone Detection

Divides the court into zones (top, wings, corners, elbows). Counts players in each zone to identify formations.

📊 Pattern Matching

Compares player distribution to known formation templates. Confidence scores indicate how certain the detection is.

📈 Confidence Scoring

Each detection includes a 0-100% confidence score based on how closely the positions match the formation template.

💡 Counter Library

Each formation is linked to a counter-strategy. The system pulls the appropriate counter when a formation is detected.

In-Game Application

During games, coaches often spend too much time identifying formations and not enough time planning counter-strategies. Voop eliminates the identification step — it tells you what the opponent is running before you even finish analyzing their lineup.

The system also tracks which formations opponents use most frequently and in which situations (close games, end of quarters, after timeouts). This data helps coaches prepare specific counter-plans for the most common scenarios they'll face.

For example, if an opponent runs Horns offense 70% of the time in crunch situations, coaches can practice defending it in practice — with specific assignments for each player on how to deny the high post entry and force sideline action.
